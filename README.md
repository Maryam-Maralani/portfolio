# Maryam Maralani — Portfolio

UX/UI portfolio of Maryam Maralani, Digital Creative student at Hyper Island, Stockholm.
Live site: https://maryam.maralani.eu/

## How it's made
- Designed in Figma.
- Coded with Claude (Anthropic) from the Figma designs, then reviewed and adjusted by me.
- Plain HTML, CSS and a little JavaScript. No framework, no build step.
- Hosted on Netlify.

## Accessibility
- WCAG 2.2 AA colour contrast
- Full keyboard navigation with visible focus
- Respects "reduce motion" settings
